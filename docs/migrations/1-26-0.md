Wave 1.26.0 was released on October 16, 2025.

## Mandatory steps

Wave 1.26.0 replaces the default security scanner image with a Seqera-hosted image that bundles
Trivy and ORAS:

| Setting | Before | After |
|---|---|---|
| `wave.scan.image.name` | `aquasec/trivy:0.65.0` | `public.cr.seqera.io/wave/scanner:v1-0.65.0-oras-1.3.0` |

If scanning is enabled and your deployment restricts which registries it can pull from, allow
`public.cr.seqera.io` — or mirror the image and set `wave.scan.image.name` to your copy. Scan jobs
fail to start otherwise.

The scanner also downloads its vulnerability databases from `public.ecr.aws/aquasecurity/trivy-db`
and `public.ecr.aws/aquasecurity/trivy-java-db`, set through `wave.scan.environment`. These are
unchanged, but review them at the same time if egress from scan jobs is restricted.
