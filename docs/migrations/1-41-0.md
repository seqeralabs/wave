title: Migrating to 1.41.0
tags: [migration notes, wave]

Wave 1.41.0 was released on October 18, 2026.

## Mandatory steps

Wave 1.41.0 changes the default of `wave.security.ssrf-protection.enabled` from `true` to `false`.
The SSRF check on the `/validate-creds` endpoint, added in [1.33.0](./1-33-0.md), is therefore off
unless you enable it explicitly.

If your installation relies on that check to stop users registering credentials for internal hosts,
add the setting to your Wave configuration file:

```yaml
wave:
  security:
    ssrf-protection:
      enabled: true
```

If you disabled the check after upgrading to 1.33.0 — the common case, because it rejects
registries on private networks — no action is required, and you can remove the override.
