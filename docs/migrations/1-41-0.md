title: Migrating to 1.41.0
tags: [migration notes, wave]

Wave 1.41.0 was released on October 18, 2026.

## Mandatory steps

Wave 1.41.0 changes the default of `wave.security.ssrf-protection.enabled` from `true` to `false`:
the `/validate-creds` SSRF check added in [1.33.0](./1-33-0.md) is off unless you enable it
explicitly. Upgrading from a release before 1.33.0 needs no action — the check is off by default,
as it was then.

If your installation relies on that check to stop users registering credentials for internal hosts,
add the setting to your Wave configuration file:

```yaml
wave:
  security:
    ssrf-protection:
      enabled: true
```

If you disabled the check after upgrading to 1.33.0, no action is required and you can remove the
override.
